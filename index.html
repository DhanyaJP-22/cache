About the experiment
(i) Row-major vs column-major traversal of a C-order matrix; (ii) naive vs cache-blocked (tiled) transpose; (iii) Array-of-Structures (JS objects) vs Structure-of-Arrays (typed arrays) for memory and scan time; (iv) pointer chasing in a randomly permuted linked list vs a contiguous array scan. The original lab used Python/NumPy; this version uses JavaScript typed arrays, so absolute times differ but the cache effects are the same. Results vary with the browser, device and CPU load.
